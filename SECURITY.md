# Security Policy

## Reporting a vulnerability

Please report security issues privately by email to **info@hasibulhasansakib.com**. Do not open a public GitHub issue.

Include the plugin version, steps to reproduce and the impact. You will get a reply within 3 business days, and a fix will be released as quickly as possible. You will be credited in the changelog unless you prefer otherwise.

## Supported versions

Only the latest release receives security fixes.
